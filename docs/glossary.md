# 卓譜 用語集（Glossary）

画面・コード・ドキュメントで使う表記をここで統一する。表現を増やさず、利用者が迷わない最小の語彙だけを使う。

## 役割・人

| 統一表記 | 意味 | 避ける表現 |
|---|---|---|
| `GM` | ゲームマスター／セッションの進行役（システム不問） | `KP`、`KP:`、`進行`、`キーパー`、`D&Dマスター` |
| `PL` | プレイヤー（参加者） | `参加`（役割対比のラベルとして使う場合） |
| `PC` | プレイヤーキャラクター（PL が操作する探索者・冒険者） | — |
| `NPC` | ノンプレイヤーキャラクター（GM が動かす登場人物） | — |
| `システム` | ログ上のシステム進行メッセージ (`SYSTEM`) | — |
| `プロフィール` | 利用者ページ・設定から開く自身のページ | `マイページ` |
| `ログイン` / `ログアウト` | Google アカウントで卓譜に入る・出る。ボタンは Google の指定どおり「Google でログイン」 | `サインイン`、`サインアウト` |

> 備考: CCFOLIA やテキストログの**入力データ**に含まれる `KP:` などの接頭辞は、パーサー（`src/lib/ccfolia-parser.ts` / `src/lib/speaker-match.ts`）が内部で解釈して `kind: "KP"` または `"GM"` として取り込むが、**画面上の表示ラベル・選択肢・フィルタはすべて `GM` に統一する**。

## 領域・機能

| 統一表記 | 意味 | 備考 |
|---|---|---|
| `セッション` | 遊んだ 1 回のプレイ記録（ログ付き・手入力どちらも） | 一覧見出し・行は `セッション` |
| `卓` | 一緒に遊ぶメンバーのグループ | システムは固定しない。作成時は「卓名」と「メンバー」だけを求める |
| `シナリオ` | 遊んだ／遊ぶ予定の作品メタ情報 | 一覧には作品名・作者・システムだけを出し、配布元サービス名は並べない |
| `通過済み` | 自分がそのシナリオを遊んだ状態 | 落ち着いた補助文字（`text-ink2`）で示す |
| `日程調整` | 複数の候補日を挙げて参加可否（◯ / △ / ×）を集める予定 | 確定した `予定` とは分けて扱う |
| `共有範囲` | セッションごとの公開単位（`メンバー限定` / `プレイした人` / `公開`） | `SCOPE_META` の文言だけを使う |
| `卓報告カード` | セッションの参加メンバー・日時をまとめた X 共有用画像 | `#卓報告` などの定型タグを押し付けない |

## 時間の表記

| 統一表記 | 形式・用途 |
|---|---|
| 所要時間 | `3時間2分`（`fmtDur` のみ。`3h2m` は禁止） |
| 日付 | `todayStr()` / `fmtDate()` / `fmtDateShort()` |
| 相対日 | `今日` / `あす` / `あとN日`（`relativeDayLabel`） |
