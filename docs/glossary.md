# 卓譜 用語集（Glossary）

画面・コード・ドキュメントで使う表記をここで統一する。表現を増やさず、利用者が迷わない最小の語彙だけを使う。

## 役割・人

役割の呼び方は**文脈で決める**（P8）。

- **1 つのセッション・キャラクターの画面**（セッション詳細・共有ページ・ログ・記録の発言者設定・招待・キャラクター詳細）では、**そのシステムの言葉**を使う。例: クトゥルフ神話TRPG（6版・7版・パルプ・クトゥルフ）は `KP`、ネクロニカは `ネクロマンサー`、エネミーのいるシステム（ダブルクロス・アリアンロッド・ログ・ホライズンなど）は `エネミー`、ソード・ワールドは `魔物`。
- **システムをまたぐ画面**（一覧・絞り込み・ナビ・ホーム・カレンダー）では一般語の `GM` / `PL` を使う。
- 画面に文字を直に書かず、`roleLabel(systemId, role, "system" | "generic")`（`src/lib/roles.ts`）を通す。システムごとの呼び方は `SystemDef.roles`（`src/data/systems.ts`）に書く。書いていないシステムは一般語。

| 役割（`RoleKey`） | 一般語     | 意味                                                                        | 避ける表現                                                |
| ----------------- | ---------- | --------------------------------------------------------------------------- | --------------------------------------------------------- |
| `GM`              | `GM`       | ゲームマスター／セッションの進行役。システムの言葉があればそれ（`KP` など） | `進行`、`キーパー`、`D&Dマスター`、`KP:` を文字で書くこと |
| `PL`              | `PL`       | プレイヤー（参加者）                                                        | `参加`（役割対比のラベルとして使う場合）                  |
| `PC`              | `PC`       | プレイヤーキャラクター（PL が操作する探索者・冒険者）                       | —                                                         |
| `NPC`             | `NPC`      | ノンプレイヤーキャラクター（GM が動かす登場人物）                           | —                                                         |
| `ENEMY`           | `エネミー` | 敵として出る登場人物。エネミーのいるシステムだけ発言者の役割に出す          | —                                                         |

| 統一表記                  | 意味                                                                                   | 避ける表現                   |
| ------------------------- | -------------------------------------------------------------------------------------- | ---------------------------- |
| `システム`                | ログ上のシステム進行メッセージ (`SYSTEM`)                                              | —                            |
| `描写`                    | 場面・場所の見出しやあらすじの名前で GM が流す地の文 (`NARRATION`)。登場人物ではない   | `NPC`（人物でないものを指して） |
| `プロフィール`            | 利用者ページ・設定から開く自身のページ                                                 | `マイページ`                 |
| `ログイン` / `ログアウト` | Google アカウントで卓譜に入る・出る。ボタンは Google の指定どおり「Google でログイン」 | `サインイン`、`サインアウト` |

> 備考: CCFOLIA・Udonarium の**入力データ**に含まれる `KP:` などの接頭辞は、パーサー（`src/lib/ccfolia-parser.ts` / `src/lib/speaker-match.ts`）が内部で解釈して `kind: "KP"` または `"GM"` として取り込む。どちらも役割は `GM`（進行役）として扱い、**表示するときは `roleLabel` でそのシステムの言葉（CoC なら `KP`）か一般語（`GM`）に直す**。データ上の `"KP:"` 接頭辞を UI の文字として直に書かない（`lint:KP:`）。

## 領域・機能

| 統一表記       | 意味                                                                 | 備考                                                                           |
| -------------- | -------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `セッション`   | 1 つのシナリオを通しで遊んだ 1 回（ログ付き・手入力どちらも）        | 名前を持たず、シナリオの題名で呼ぶ。何夜かに分けたら遊んだ回が複数になる       |
| `卓`           | 一緒に遊ぶメンバーのグループ                                         | システムは固定しない。作成時は「卓名」だけを求め、メンバーは招待リンクで加わる |
| `ユーザー ID`  | `@` の後ろに書く、人を見分ける変わらない名前（英小文字・数字・_）    | 「ハンドル」「ユーザー名」と書かない。表示名とは別                             |
| `表示名`       | 一緒に遊ぶ人に見える名前。いつでも変えられる                         | 「ニックネーム」と書かない                                                     |
| `招待リンク`   | 卓に加わってもらうための URL（`/join/…`）                            | セッションの招待（`/invite/…`）とは別。「招待コード」と書かない                |
| `参加者の招待リンク` | セッションに参加者として加わってもらうための URL（`/invite/…`）  | 卓の招待リンクと同じ「招待リンクを作る」にしない                               |
| `はじめの設定` | 初めてログインしたときの ID・表示名・アイコンの設定                  | 「オンボーディング」「ようこそ」を画面に出さない                               |
| `シナリオ`     | 遊んだ／遊ぶ予定の作品メタ情報                                       | 一覧には作品名・作者・システムだけを出し、配布元サービス名は並べない。セッションには必ず 1 つ。作者が分からなければ空のままにして出さない（「作者未設定」「不明」と書かない） |
| シナリオの `共有範囲`（`セッションと同じ` / `全員`） | 足したシナリオがだれに見えるか（`Scenario.private`）。`セッションと同じ` は検索に出さず、そのシナリオのセッションを読める人（卓のメンバーなど）にだけ題名が見える。`全員` はだれでも探して選べる | 既定は配布ページがあれば `全員`、なければ `セッションと同じ`。`自分だけ` とは書かない（卓の人には見えるため）。`全員` にしたものは戻せない。裏の一覧に名前を付けて画面に出さない（「目録」「みんなのシナリオ」と書かない） |
| `修正を提案`   | ほかの人が足したシナリオの情報を直すよう、足した人に送ること         | 「編集を申請」と書かない                                                       |
| `通過済み` / `未通過` | 自分がそのシナリオを遊んだ／まだ遊んでいない状態。共有範囲の `通過した人`、共有ページの「通過済みなので開く」も同じ言葉 | 「プレイした人」「プレイ済み」と書かない。落ち着いた補助文字（`text-ink2`）で示す |
| `日程調整`     | 複数の候補日を挙げて参加可否（◯ / △ / ×）を集める予定                | 確定した `予定` とは分けて扱う                                                 |
| `共有範囲`     | セッションごとの公開単位（`メンバー限定` / `通過した人` / `公開`）。関連するもの（録画など）は `自分だけ` / `指定した人` も | `SCOPE_META` の文言だけを使う。見出しも `共有範囲`（「公開範囲」「読める人」「見られる人」と書かない） |
| `キャラクター` | PL が操作するキャラクター。外部のシートは `キャラシ`                  | 「カルテ」と書かない。システムをまたぐ画面で「探索者」と書かない（P8）         |
| `サンプル`     | ログインせずに試すときのサンプルデータ・サンプルの利用者              | 「デモ」と書かない                                                             |
| `卓報告カード` | セッションの参加メンバー・日時をまとめた X 共有用画像                | `#卓報告` などの定型タグを押し付けない                                         |
| `連携`         | 卓譜のアカウントと外部のアカウント（Google・X・Discord）を結ぶこと。設定の「連携する」「連携を解除」 | 「接続」「リンク」と書かない                                                   |
| `つなぐ`       | 卓と Discord のチャンネルを結ぶこと。Discord で `/卓譜 つなぐ`、卓の画面の「Discord」で「解除」       | アカウントの「連携」と混ぜない                                                 |

## 時間の表記

| 統一表記 | 形式・用途                                        |
| -------- | ------------------------------------------------- |
| 所要時間 | `3時間2分`（`fmtDur` のみ。`3h2m` は禁止）。予定の入力・シナリオの実績も `所要時間`（「長さ」「プレイ時間」と書かない） |
| 日付     | `todayStr()` / `fmtDate()` / `fmtDateShort()`     |
| 相対日   | `今日` / `あす` / `あとN日`（`relativeDayLabel`） |

## 遊んだ日時

| 統一表記     | 意味                                                                                                 | 避ける表現                                 |
| ------------ | ---------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| `遊んだ日時` | セッションの集まり（`Log.sittings`）。1 回ごとに開始と終了の日時を持つ。何夜かに分けて遊んだら複数回。入力の各行は `1回目` / `2回目` | `実施日` |
| 日付の並び   | 複数回のセッションは日付を並べる（「11月8日(土)・15日(土)」）。回数は数えれば分かるので添えない（P5）   | `（2回）`、`N日間`（間の日も遊んだように読める） |
| `25:00`      | 終わりが開始の翌日の回は 24 を足して書く（「21:00〜25:30」。2026-11-22 に `翌` から改めた）           | `翌`、`翌01:30`                            |

## コードの名前と画面の言葉

型・欄の名前は保存データと結び付いているので変えない。新しいコードでもこの対応で読み替える。画面に出す文字は `lint:glossary`（`scripts/lint-design.ts`）と `audit:banned-copy`（`e2e/design-audit.ts`）で「避ける表現」を検査する。

| コード | 画面の言葉 | 備考 |
| --- | --- | --- |
| `Log` / `State.logs` | セッション | ログ（発言の記録）は `Log.channels`。セッション全体を「ログ」と呼ばない |
| `Log.sittings` / `Sitting` | 遊んだ日時（1回目・2回目） | |
| `sessionTitle(log, scenarios)` | セッションの呼び名（= シナリオの題名） | セッションは名前を持たない |
| `Scenario.private` | シナリオの共有範囲: セッションと同じ | `false` / なしは `全員` |
| `scenarios` コレクション・`scenario-directory`・`/api/scenarios` | （画面に名前を出さない） | docs・コメントでは「共有シナリオ一覧」。TALTO から取った元の一覧（`scripts/data/talto-catalog.json`）は「TALTO の一覧」 |
| `Scope`（`members` / `passed` / `public`） | 共有範囲（メンバー限定 / 通過した人 / 公開） | |
| `sharedLogs/{slug}`（文書） | 共有ページ | 文書そのものは docs で「共有ページの見出しの文書」 |
| `TableInvite`（`/join/…`） / `SharedInvite`（`/invite/…`） | 招待リンク / 参加者の招待リンク | |
