# セッションに紐付く「関連するもの」 利用場面調査

調査日: 2026-11-21。出典は X（grok の x_keyword_search / x_semantic_search / x_thread_fetch による 9 回の検索）と Yahoo!リアルタイム検索（curl で取得できた。録画・タイムスタンプ・Craig の投稿を照合した）。各行の根拠は実際に返ってきた投稿で、grok が本文を要約したもの。画像や外部ページ（ふせったー・Privatter・ポイピク）の中身は開いていない。**推測** と書いたものは投稿から直接は言えない、筆者の解釈。

## 要点

- セッションの周りにできるものは、**記録**（録画・録音・ログ・ルームデータ）、**創作物**（立ち絵・スチル・卓絵・エンドカード・漫画・SS・イメソン）、**報告と感想**（卓報告・ネタバレ感想・通過証）、**準備物**（HO・KP メモ・シナリオ頒布ページ・日程）、**公開コンテンツ**（配信・リプレイ動画）の 5 系統に分かれる。
- 置き場所は X の外に散らばっている（YouTube 限定公開、Google ドライブ、ギガファイル便、ふせったー、Privatter、ポイピク、Notion、BOOTH、Spotify、pixiv、Skeb）。X は「ここにある」というリンクと卓ハッシュタグを置く場所になっている。
- どの系統でも、ネタバレを隠す仕組み（「現行・未通過×」、ふせったーの合言葉、ポイピクのパスワード）と、見せる相手の区別（同卓者だけ／通過者／一般）が付いてくる。秘匿 HO がある卓では、同卓者でも「誰の視点か」で見てよいものが変わる。
- 録画は長い（4〜12 時間）、何本にも分かれる、壊れる・消える。そのため **タイムスタンプ（場面の目次）** と **複数ファイルの保存・共有** が繰り返し困りごととして出てくる。

## 2. どの系統にも出てくる要件

### 2-1. ネタバレを隠す仕組み

- 慣習は 3 段階に整理できる（推測）。**見えるが中身は隠す**（ふせったーの伏字、ポイピクのパスワード）、**閲覧者を宣言で絞る**（「現行・未通過×」「プレイ予定のない人だけ」）、**出さない**（「PC の存在そのものがネタバレ」なので画像を出さない [s1imo](https://x.com/s1imo/status/2123912814842835208)）。
- 卓譜の `Scope`（`members` / `passed` / `public`）と `SessionImpression.spoiler` はこの慣習にそのまま対応する。関連するものにも、1 件ずつ公開範囲とネタバレの有無を持たせる必要がある。ネタバレ扱いのサムネイルはぼかすか隠す（推測）。
- 「ネタバレなしでも読める範囲」を先に書く人がいる（[MU_trpg_kiseki](https://x.com/MU_trpg_kiseki/status/2102403090037211178)）。1 件ごとに短い注意書きを入れられると、この慣習に合う。

### 2-2. 秘匿 HO による視点の区別

- 同卓者どうしでも、他の HO の秘匿は卓中には見せない。録画・ログ・HO 文書には「誰の視点か／どの HO の秘匿を含むか」がある（[youmayoi](https://x.com/youmayoi/status/2123021326961307656)、[TRPG224](https://x.com/TRPG224/status/1768830056108027976)）。
- 卓後に KP が秘匿を開く（[otyauke_shura](https://x.com/otyauke_shura/status/1424655221859381249)、[s_gram_es](https://x.com/s_gram_es/status/2099861592011882590)）。公開範囲を「特定の人だけ → 同卓者全員」と後から広げられる必要がある。卓譜の `Channel.secret` と同じ考え方を、関連するものにも広げる（推測）。

### 2-3. 長い録画、分割、タイムスタンプ

- 1 本 4〜6 時間、1 日で 12 時間（[COC_TKO](https://x.com/COC_TKO/status/1810946087018258555)、[kurokago03](https://x.com/kurokago03/status/2121804660751351914)）。Craig は 6 時間で止まり、YouTube の配信録画は勝手に 2 本に分かれる（[kataruma_vtuber](https://x.com/kataruma_vtuber/status/2090620097790615918)）。リプレイ動画は Part 1〜N、総集編、再生リスト単位になる。
- そのため、1 件に **複数のパート（順序付き）** や再生リストを持たせ、**時刻付きの目次（タイムスタンプ）** を付けられるとよい。タイムスタンプは多くの人がやりたいのに手間で後回しになっている。卓譜にはログの時刻（`t0` / `t1` と発言時刻）があるので、録画の開始時刻を合わせればログの発言から録画のその位置へ飛べる（推測。[Pa_Mu_Da](https://x.com/Pa_Mu_Da/status/2030925004221858296) や [kanata_trpg_](https://x.com/kanata_trpg_/status/2114355842682376647) の「ログと音声を揃えて見返したい」需要に当たる）。
- 継続卓は日を分けて遊ぶので、録画・配信は実施日（`dates`）ごとに付く（[Kokon_1102](https://x.com/Kokon_1102/status/2123022817524691053)）。

### 2-4. 消える・壊れる・置き場が散る

- HDD の故障、ギガファイル便の期限、ファイルの破損、ココフォリアの部屋・ログ・BGM の消失が繰り返し出てくる（[I_Tks5iko0HsD](https://x.com/I_Tks5iko0HsD/status/1823580299319726580)、[narumotitrpg](https://x.com/narumotitrpg/status/2021429247160770628)、[Snufkin1978](https://x.com/Snufkin1978/status/2121156578938421360)）。「同卓者の誰が持っているか」が分かるだけでも復旧に役立つ（推測）。
- 期限付きリンク（ギガファイル便）は期限を記録し、切れたら「期限切れ」と表示する（推測）。
- ファイルを預かるかどうか: 録画は数 GB〜TB 単位なので預かるのは現実的でない。**URL で紐付けるのが基本** で、画像（立ち絵・スチル・通過証・エンドカード）、ログの HTML・ZIP、HO の PDF のような小さいものだけアップロードを考える（推測）。

### 2-5. 誰が足せるか、誰が作ったか

- 足す人は 1 人ではない。KP（HO・録画・あらすじ・BGM）、各 PL（イメソン・立ち絵・感想・卓絵）、外部の絵師（Skeb）、視聴者（切り抜き・ファンアート）がいる。同卓者が各自で足せて、足した人と作者（絵師・サムネ作者・エンドカード作者）を別に記録できる必要がある（[zokubutsu_333](https://x.com/zokubutsu_333/status/2122681113185521761) の「エンドカード：みき」、[D_the_blackhawk](https://x.com/D_the_blackhawk/status/2122994304381866396)）。
- 足した人が消せること、KP（部屋主）が不適切なものを外せることも要る（推測）。

### 2-6. 録画の同意と、シナリオ作者の許可

- 無断で録画・配信しないでほしい（[BTSpugMMystery](https://x.com/BTSpugMMystery/status/1988768486525661685)）、全員の許可が取れたときだけ録る（[ruri_trpg8](https://x.com/ruri_trpg8/status/2001631077350412432)）、第三者には同卓者の許可があって信用できる相手にだけ渡す（[EbeMari_TRPG](https://x.com/EbeMari_TRPG/status/1802177131956383790)）。配信は NG で録画の共有は OK、という区別もある（[Hb0K2__](https://x.com/Hb0K2__/status/2108508356499718305)）。
- そのため、録画を足すときは「同卓者の許可を得ている」ことを確かめ、同卓者が自分の映った録画への異議を出せるとよい（推測）。参加者ごとに「録画可 / 配信可」の希望を持てると、卓前の確認にも使える（推測）。
- 公開の動画化にはシナリオ作者の配信ガイドラインがあり、頒布ページ URL とクレジットが条件になることがある（[cthulhumasters](https://x.com/cthulhumasters/status/1920392888145621338)）。シナリオに頒布 URL とガイドライン URL を持たせれば、概要欄用のクレジット文を組み立てられる（推測。[sakuramoti2075](https://x.com/sakuramoti2075/status/2123640097103134866) は概要欄用のクレジット文を同卓者に作って渡している）。

### 2-7. 埋め込みとリンク

- YouTube、ニコニコ、Twitch、Spotify は埋め込みで見られる。限定公開の YouTube も URL を知る人には埋め込める。ただし限定公開の URL そのものが共有範囲の鍵なので、`public` の共有ページに載せない扱いが要る（推測。[miroku_TRPG](https://x.com/miroku_TRPG/status/2084188849849434317) は URL を共有しない限定公開）。
- ふせったー、Privatter、ポイピクはネタバレを隠すための置き場なので、**埋め込まずリンクで出す** のが慣習に合う（推測）。
- 紐付け先はセッションだけでなく、キャラクター（立ち絵・イメソン・ファンアート）、シナリオ（頒布ページ・ガイドライン）、卓（継続卓のハッシュタグ・再生リスト）にも分かれる。セッションの「関連するもの」に、キャラクターやシナリオに付いたものを表示できるとよい（推測）。
